W05 Project: Site Plan

1. Site Name

Site Name: Zeph Graphics Portfolio

This name represents my personal brand as a graphics designer, aligning with my professional identity and communicating creativity and digital expertise.

2. Site Purpose

The purpose of this website is to serve as a professional online portfolio showcasing my graphic design works, skills, and services. The site will allow potential clients to:

  • View examples of my completed projects.
  • Learn about my design skills and services offered.
  • Contact me for collaborations or commissions.

3. Scenarios

  • "I want to see your previous design work before hiring you."
  • "How can I contact you to request a graphic design project?"
  • "Do you offer logo design, flyers, banners, and branding packages?"

4. Color Schema

The following colors will be used across the website:

#004c6d — Used for headers, navigation, and major accents.

#e0c300 — Used for highlights and call-to-action buttons.

#f5faff — Used as the main page background.

5. Use of Color Schema

The selected colors above are already applied in this document to demonstrate how the color palette will be used throughout the site.

6. Typography

Primary Font: Segoe UI

This clean and modern font will be applied to all headings, paragraphs, and navigation items across the portfolio site.
